# Task Plan: RK3568 + PG2L100H ADAS Open-Source Research

## Goal

Identify reusable, license-compatible open-source projects for the 2026 FPGA
innovation contest ADAS topic on the official RK3568_MES2L100H platform.

## Scope

- Read-only research. No FPGA, Linux, or board-support code will be changed.
- Verify the board identity from the supplied contest guide.
- Record project purpose, upstream revision, license, integration boundary, and
  the evidence needed before adoption.

## Phases

- [x] Phase 1: Establish board identity and research categories.
- [x] Phase 2: Find and verify upstream candidates.
- [x] Phase 3: Map candidates to the staged contest demonstration.
- [x] Phase 4: Publish the adoption shortlist and risk register.
- [x] Phase 5: Audit local official examples and map them to Topic 3 requirements.
- [x] Phase 6: Define three-person implementation order, ownership, interfaces, and acceptance gates.
- [x] Phase 7: Expand the plan to the full Topic 3 implementation and verification lifecycle.
- [x] Phase 8: Create a comprehensive project knowledge map and fast-start guide without team allocation.
