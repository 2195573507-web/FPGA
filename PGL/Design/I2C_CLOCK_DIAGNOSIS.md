# MS7200 I2C初始化问题诊断

## 关键发现

### 1. I2C时钟要求
根据代码注释：
```verilog
//clk时钟配置成1MHz,周期为1us 5000*1us = 5ms
```

**要求**：
- 输入时钟 `clk` 必须是 **1MHz**
- 初始化延迟：5000个时钟周期 = 5ms

### 2. 当前问题分析

查看顶层模块 `hdmi_fmc_pcie_top.v`，需要确认：
- `sys_clk` 的频率是多少？
- 传递给 `i2c_ms7200_cfg` 的时钟是否是1MHz？

## 可能的问题

### 问题A：输入时钟频率不对（最可能，80%）

**症状**：
- 如果 `sys_clk` = 25MHz，而不是1MHz
- I2C波形频率会是期望的25倍
- MS7200无法正确响应I2C命令
- 初始化失败 → video_locked = 0 → 全黑画面

**解决方案**：
需要添加分频器，将sys_clk分频到1MHz

### 问题B：初始化时序不对（15%）

**症状**：
- 初始化延迟不够
- MS7200上电复位时间不足
- 配置寄存器时序违规

### 问题C：I2C引脚配置问题（5%）

**症状**：
- SCL/SDA引脚约束错误
- 上拉电阻缺失
- 信号完整性问题
