# HDMI-FMC-PCIe-RK3568 系统诊断

## 系统架构（正确理解）

```
┌─────────────────────────────────────────────────────┐
│  电脑 (Windows/Linux)                              │
│  输出 HDMI 信号 1920×1080@60Hz                     │
└────────────────┬────────────────────────────────────┘
                 │ HDMI 线
                 ↓
┌─────────────────────────────────────────────────────┐
│  FMC HDMI 接收卡 (ATK FMC_HDMI_4K30)               │
│  · 接收 HDMI 信号                                  │
│  · 输出 RGB888 (8bit R + 8bit G + 8bit B)        │
│  · 输出同步信号 (HSYNC, VSYNC, DE/VALID)         │
└────────────────┬────────────────────────────────────┘
                 │ FMC 40pin 接口
                 ↓
┌─────────────────────────────────────────────────────┐
│  FPGA (Pango)                                      │
│  · FMC 接口接收 RGB888 + 同步信号                 │
│  · 处理/缓存视频数据                               │
│  · PCIe 接口输出数据                               │
└────────────────┬────────────────────────────────────┘
                 │ PCIe 2条线 (x2 或 x4)
                 ↓
┌─────────────────────────────────────────────────────┐
│  RK3568 (ARM开发板)                                │
│  · PCIe 接口接收视频数据                           │
│  · 处理/显示/录制视频                              │
└─────────────────────────────────────────────────────┘
```

## 核心问题理解

**你的问题**: "连接上了电脑没显示HDMI设备"

**实际诊断**:
- ❌ 不是"电脑看不到HDMI设备"
- ✓ 应该是"RK3568 看不到 FPGA 的 PCIe 设备"
- ✓ 或者是"电脑连接 FPGA 只是为了加载比特流"

---

## 第一步：确认比特流加载

1. 连接 FPGA 到电脑 (JTAG/USB)
2. 打开 PGL IDE，生成并加载比特流
3. 观察 FPGA 上的 LED 是否亮起

---

## 第二步：RK3568 PCIe 设备识别

**连接到 RK3568 的 Linux 终端，执行**:

```bash
# 1. 列出所有 PCIe 设备
lspci

# 2. 查看详细信息
lspci -vvv

# 3. 查看内核日志
dmesg | grep -i pcie

# 4. 检查设备文件
ls -la /sys/bus/pci/devices/

# 5. 查看 Device ID
cat /sys/bus/pci/devices/0001:01:00.0/device
cat /sys/bus/pci/devices/0001:01:00.0/vendor
```

## 常见问题排查

### 问题1: lspci 看不到 FPGA 设备

**原因**:
- PCIe 线未牢固连接 → 重新插拔
- FPGA 比特流未加载 → 重新加载
- PCIe 端口被禁用 → 检查硬件设置

### 问题2: 看到 "Unknown Device"

**说明**:
- 硬件连接正常 ✓
- 没有驱动程序 ✗

**解决**:
- 在项目中查找驱动程序源码
- 编译并加载驱动
