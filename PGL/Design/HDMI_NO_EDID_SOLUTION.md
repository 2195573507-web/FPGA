# Win+P无法切换 - 电脑HDMI输出问题诊断

## 问题现象
按Win+P后无法切换显示模式，说明电脑没有检测到第二个显示器。

## 可能原因

### 原因1：FMC卡没有EDID信息（最可能，80%）

**什么是EDID？**
- EDID = Extended Display Identification Data
- 显示器通过HDMI向电脑报告自己的能力（分辨率、刷新率等）
- 普通显示器有EDID芯片，会主动告诉电脑"我在这里"
- **FMC采集卡通常没有EDID芯片**，所以电脑检测不到

**影响**：
- 电脑不知道连接了什么设备
- Win+P看不到第二个显示器
- 但**不影响HDMI信号输出**！

**解决方案**：
1. 使用EDID模拟器（硬件设备）
2. 强制电脑输出到HDMI
3. 修改FMC卡添加EDID芯片（硬件改造）

---

### 原因2：HDMI接口/线缆问题（15%）

**检查方法**：
```
1. 用普通显示器测试这个HDMI口 → 能显示则接口正常
2. 用这根HDMI线连接显示器 → 能显示则线缆正常
3. 尝试不同的HDMI口（如果有多个）
```

---

### 原因3：显卡驱动/设置问题（5%）

**检查方法**：
```
1. 右键桌面 → 显示设置 → 检测显示器
2. 打开显卡控制面板（NVIDIA/AMD）→ 查看输出配置
3. 设备管理器 → 显示适配器 → 检查驱动是否正常
```

---

## 解决方案A：强制HDMI输出（无需EDID）

### 方法1：通过显卡控制面板

**NVIDIA显卡**：
```
1. 右键桌面 → NVIDIA控制面板
2. 显示 → 设置多个显示器
3. 手动添加自定义分辨率：1280×720@60Hz
4. 应用到HDMI输出
```

**AMD显卡**：
```
1. 右键桌面 → AMD Radeon设置
2. 显示器 → 创建自定义分辨率
3. 设置为1280×720@60Hz
4. 应用
```

**Intel核显**：
```
1. 右键桌面 → 显卡设置
2. 显示器 → 自定义分辨率
```

### 方法2：使用EDID模拟器（推荐）

**什么是EDID模拟器？**
- 一个小的HDMI转接头
- 内置EDID芯片，模拟显示器
- 让电脑以为连接了真实显示器

**连接方式**：
```
电脑HDMI → EDID模拟器 → HDMI线 → FMC卡
```

**价格**：约20-50元人民币
**型号推荐**：
- "HDMI EDID模拟器"
- "HDMI假负载"
- "HDMI虚拟显示器"

## 解决方案B：修改注册表强制输出（Windows）

⚠️ **警告**：修改注册表有风险，请先备份！

### 步骤

1. **打开注册表编辑器**
```
Win+R → 输入 regedit → 回车
```

2. **导航到显卡配置**
```
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Class\
{4d36e968-e325-11ce-bfc1-08002be10318}\0000
```

3. **添加自定义分辨率**
（具体方法因显卡而异，建议先尝试方案A）

## 解决方案C：使用第三方软件

### Custom Resolution Utility (CRU)

**功能**：
- 手动编辑显示器的EDID信息
- 添加自定义分辨率
- 强制输出到HDMI

**下载**：
- 搜索 "Custom Resolution Utility CRU"
- 开源免费工具

**使用步骤**：
```
1. 运行CRU
2. 选择HDMI输出
3. 添加标准分辨率：1280×720@60Hz
4. 重启显卡驱动
```

## 临时测试方法

### 验证HDMI信号是否输出

即使Win+P不能切换，HDMI口可能仍在输出信号。

**测试方法**：
```
1. 将FMC卡保持连接
2. 播放视频或打开图片
3. 在RK3568上运行接收程序
4. 查看是否收到非零数据
```

**如果还是全0** → 确实没有HDMI输出

## 判断方法

**场景1：用显示器测试HDMI口能正常显示**
→ HDMI接口正常，问题是FMC卡没有EDID
→ 解决：使用EDID模拟器或强制输出

**场景2：显示器也不能识别**
→ HDMI接口或线缆问题
→ 解决：检查线缆、驱动、换其他HDMI口

**场景3：其他HDMI口可以，这个口不行**
→ 特定接口故障
→ 解决：使用其他HDMI口
